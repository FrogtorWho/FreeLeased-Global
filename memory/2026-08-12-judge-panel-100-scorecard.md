## Methodology

See [project/strategy/gauntlet-loop.md §Convergence Audit Methodology](../../project/strategy/gauntlet-loop.md) for the documented procedure.

**Procedure:**
1. Load 100 judge personas from `data/judge-panel-100.json`.
2. For each judge, take the two axes they judge.
3. For each axis, find the strongest verifiable claim in the snapshot whose `axisScores[axis]` is defined.
4. Score = min(10, claim_score + tilt) where tilt = 0.2 if judge weight > 1, else 0.
5. Per-judge weighted summary = Σ(score × weight) / Σ(weight).
6. Re-run scoring pipeline and JSON-diff output to verify reproducibility.
7. `scripts/audit-trail-verifier.ts` walks each claim in the scorecard and asserts source + fetch + conviction.
