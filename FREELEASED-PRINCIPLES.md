# FreeLeased — Binding Principles (standing brief)

These are locked. Every module, engine, agent, process and line of code inherits them.
Every specialist sub-agent (fl-*) must read and obey this file.

## The eight rulings (2026-08-05)

1. **Gates on UI copy too.** On-screen interface text must pass the 4 binding gates:
   no em-dash chains, no AI-tell vocabulary (leverage, robust, ecosystem, delve,
   moreover, seamless, etc.), UK English spelling, no PII. Not just documents.
2. **Label all modelled figures.** Any synthetic or modelled value shown in the UI
   carries an explicit evidence marker. Nothing synthetic is ever presented as
   real-world fact. Use the shared evidence tag primitive.
3. **Military-depth intelligence protocols.** The analytical layer detects AND
   predicts manipulative, deceptive, deflective, hidden, contradictory, temporal and
   exploitative technique across many disciplines, then wargames tactical and
   strategic courses of action by overlaying a plethora of doctrines
   (military / corporate / authority / organisational). Breadth is a requirement,
   not a nice-to-have. See the Intelligence Protocol Registry.
4. **Every line held to the bar.** Backend engines, routes and tests are held to the
   same craft standard as the UI: clear naming, each model's method documented in
   code, real test coverage.
5. **Proactive.** Run the review to build to verify squad to hold the whole app to
   standard without waiting for a per-module request. Report after acting.
6. **Peacock is locked.** The dark peacock identity is fixed. Refine within it.
7. **Honesty always wins.** If visual richness ever conflicts with honesty or
   clarity, honesty and clarity win, even if the screen looks plainer.
8. **Preview is enough for now.** Do not publish to a public URL until asked.

## Honesty classes for intelligence protocols
Every detection/prediction protocol declares an evidence class so confidence is never
overstated:
- **established** — grounded in peer-reviewed method (e.g. discourse analysis of
  agentless passives, argumentation-theory fallacy structure).
- **heuristic** — plausible, operationally useful, not formally validated.
- **contested** — mixed or disputed evidence in the literature (e.g. linguistic
  deception cues).
- **unfalsifiable** — named by stakeholders but not scientifically testable
  (e.g. "predictive programming"). Carried for completeness, lowest evidentiary
  weight, always flagged as such.

Rule: a protocol's evidence class sets a ceiling on the confidence any screen may
display for it. We wargame with these, we do not pretend they are certainties.
