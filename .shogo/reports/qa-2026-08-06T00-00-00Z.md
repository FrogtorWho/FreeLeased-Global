# QA Run Report — FreeLeased (FreeLeased app preview)

**Target:** https://57bf2c29-3d43-4ba6-b01a-3885c39bce04.preview.shogo.ai/

## Summary
FreeLeased renders all 9 demo tabs without hard failures, and most core interactions (tab switching, filters, accordions, and “sign-off” actions in Lease Audit) update the UI as expected. The biggest demo weakness is that much of the “product realism” is intentionally limited by synthetic/pseudonymous fixture data (called out on the Honesty tab), plus a few areas where content toggles/links are hard to validate in an automated check (notably some external links and a likely blank/hidden section in Research Desk → Maintenance). No obvious “broken” or missing pages were observed.

## Coverage (by tab)
- **Overview:** Pass (renders; tiles navigate correctly)
- **Lease Audit (Dossier Explorer):** Pass (dossier selection, internal tab switching, Accept/Reject write to UI ledger)

- **About / Honesty (Honesty):** Pass (informational; no interactive breakdown observed beyond scrolling)

## UX Issues
- [minor] **Research Desk → Maintenance toggle appears to render blank/collapsed content** after interaction in our capture (see screenshot `step-13.png`). Likely an accordion/expand state issue or content below fold.
- [minor] **Rights external citations/links not verifiable via same-tab navigation** (automation didn’t observe navigation/URL changes after clicking statutory links; likely opens in a new tab). If the demo expects in-place navigation, this is UX-hostile.
- [nit] **Rights search UX is not strongly discoverable**: after expanding “How the catalogue is constructed”, search remains far below without an in-page jump-to-result affordance.

## Console / Network Errors
None observed as visible error UI during the audit. (The tooling used here did not surface raw console/network logs line-by-line; if you want, we can re-run with an explicit console/log capture approach.)

## Tab-by-Tab Audit (what renders / interactive behavior / data quality)

### 1) Overview
**What renders:** FreeLeased wordmark header, metrics tiles (pilot residents, hidden rights, statutes, data sources), dossier sign-off state, and a “Lease Audit / Statutory diagnostics” CTA.

**Interactive elements tested:**
- Top nav tab switching to other tools.
- Overview CTA tile drives navigation into a relevant tool (clicked “Statutory diagnostics…”.)

**Data shown:** Largely synthetic/descriptive metrics; supports the rest of the demo’s internal simulation.

**UX/design quality:** Strong visual hierarchy, clear dark-theme cards, and consistent iconography.

**Demo readiness:** Good.

### 2) Lease Audit (aka Dossier Explorer)
**What renders:**
- Left: dossier list with filter controls.
- Middle: selected dossier detail (jurisdiction pill, compliance gates, resident/building/country/contracts/action-plan sub-tabs).
- Bottom: “Redaction Protocol sign-off” with **Accept dossier / Human-reviewed / Reject** and a recorded ledger message.

**Interactive elements tested:**
- Switch dossiers (e.g., **BB-R02**).
- Switch sub-tabs: Resident → Building → Action Plan.
- Click **Accept dossier** and **Reject**; UI records the decision.

**Data shown:** Clearly labeled as fixture-like inputs (e.g., pseudonyms, hashing, sample valuations). Works deterministically within the demo.

**UX/design quality:** Very demo-ready: interaction feedback is immediate and stateful.

## Recommendations (prioritized)
1. **Fix/clarify Research Desk → Maintenance “How freshness & staleness are computed”** so expanded state reliably shows content (or ensure visible content on expand).
2. **Improve external link handling for demo usability**: either open links in the same tab with obvious “back” affordance, or present an explicit “opens in new tab” cue and validate navigation.
3. **Enhance Rights search UX**: update “showing” counters immediately on filter, and/or add “jump to results” + highlight matching right cards.
4. Add a lightweight **“Console/health” status indicator** on the UI (or a dedicated “Diagnostics” section) so demo reviewers can see errors without devtools.
